# AC-06 テストの定数の参照(テスト項目 TC-06)

## 確かめ方

```
grep -nE 'LOCK_DURATION =|timedelta\(minutes=' test_i38_tc03_lock.py test_i38_tc03_lock_boundary.py test_i38_tc03_lock_concurrency.py test_i38_tc11_seed_keeps_lock.py test_i38_tc04_uniform_failure.py
→ 出力なし、exit=1(当たりなし)

grep -n 'from app.auth.service import LOCK_DURATION' (同じ 5 ファイル)

test_i38_tc03_lock.py:14
```
