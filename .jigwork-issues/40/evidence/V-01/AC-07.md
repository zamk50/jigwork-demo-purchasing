# AC-07 テストの全件(テスト項目 TC-07)

基準: テストの手順 `.jigwork-test.json` のテストがすべて通る。

## 確かめ方

- `.jigwork-test.json` の test は 3 つ(backend の pytest、frontend の vitest、frontend の playwright)。
- `~/.local/share/jigwork/bin/jig check --json` の記録 `gate.test`(seq 263、commit 8ed42a4)で、3 つとも exit 0、`tests: 154`、`failed: 0`、`ok: true`、`blocked: []`。
- 詳しくは [common-test-run.md](common-test-run.md)。

## 補足

- 検証役のサンドボックスで backend の pytest を直に流すと、一時の PostgreSQL が Unix ソケットを作れず 106 件が setup の error になった(サンドボックスの制限)。判定は jig のゲートの結果による。
- playwright は jig のゲートの手順として流れたもので、検証役がブラウザを起動したものではない。

## 判定

合格。
