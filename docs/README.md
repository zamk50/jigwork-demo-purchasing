# docs の文書の一覧

docs フォルダにある文書の一覧です。

- [spec.md](spec.md): 仕様概要。架空の会社「みなと精機」の、備品・消耗品の購買と在庫のシステムの目的・使う人・業務の流れ・欲しい機能などをまとめた文書
- [requirements/overview.md](requirements/overview.md): システム概要。システムの目的・利用者・業務の範囲・全体の構成・品質目標を書く文書
- [requirements/functions/](requirements/functions/): 機能要件。機能ごとに 1 つのファイル(FNC-001 ログインする など)
- [requirements/nfr.md](requirements/nfr.md): 非機能要件
- [requirements/glossary.yaml](requirements/glossary.yaml): 用語集
- [internal/architecture.md](internal/architecture.md): 方式設計。部品の構成・技術と版・動かし方・横断の方式・テーブルを書く文書
- [design/common/screen-rules.md](design/common/screen-rules.md): 画面共通規則。入力チェック・時間切れ・メッセージの出し方・画面の幅の規則
