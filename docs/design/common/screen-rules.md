# 画面共通規則

## 共通の入力チェック

- 必須の欄が空なら、API を呼ばずに欄の下に「入力してください」と出す([FR-021](../../requirements/functions/FNC-001.md#FR-021))。
- 社員番号の欄は、入れる文字の数を限らない。送る前に、数字 6 桁かを確かめる(次の行)。スマホでは数字のキーボードを出す。
- 社員番号が数字 6 桁でなければ、API を呼ばずに欄の下に「数字 6 桁で入れてください」と出す([FR-024](../../requirements/functions/FNC-001.md#FR-024))。
- パスワードの欄は、入れた文字を伏せて出す。

## 二重送信の防止

- 送信のボタンは、API の応答が返るまで押せなくする。

## 時間切れ

- ログインの状態は、操作のない 30 分か、ログインから 8 時間で切れる([FR-005](../../requirements/functions/FNC-001.md#FR-005)・[FR-006](../../requirements/functions/FNC-001.md#FR-006))。
- ログインの API(`POST /api/auth/login`)を除く API で 401 が返ったら、ログイン画面に移る。
- ログインの API の 401 は、ログインの失敗である。画面は移らず、ボタンの上に共通の誤りの文を出す([FR-002](../../requirements/functions/FNC-001.md#FR-002))。
- ログインの要る画面を開いたら、まず `GET /api/me` を呼ぶ。401 ならログイン画面に移る([FR-007](../../requirements/functions/FNC-001.md#FR-007))。

## メッセージの出し方

- 誤りの文は、その画面のボタンの上に赤で出す。
- 入力の誤りは、その欄の下に出す。
- 想定しない誤り(500 や通信の失敗)は「時間をおいてもう一度試してください」と出す。

## 画面の幅

- 画面は幅 375px から使える([NFR-010](../../requirements/nfr.md#NFR-010))。幅が狭いときは、項目を縦 1 列に並べる。
- ボタンと入力の欄の高さは 44px 以上にする。指で押しやすくするためである。
