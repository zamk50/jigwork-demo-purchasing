# 架空の会社「みなと精機」の、備品・消耗品の購買と在庫のシステム

出典: Issue #29 の本文にある「仕様概要」を、文の意味を変えずに移した。

**目的**: 社員が備品や消耗品の購入を依頼し、上長が決裁し、総務の購買担当が発注と入荷を記録できるようにします。いまは紙と Excel で回しています。在庫が合わず、決裁の待ちも見えません。

**使う人**(約 120 人。3 つの部署と、倉庫が 1 つ)

- 社員: 品目を探して、購入を依頼します。自分の依頼は取り消せます。
- 上長: 自部署の依頼を決裁するか、差し戻します。外出先からスマホで決裁したい、という声があります。
- 購買担当(総務の 2 人): 決裁済みの依頼をまとめて発注し、発注書を印刷して仕入先に渡します。倉庫で、入荷の検品をスマホから入力します。
- 管理者(情報システムの 1 人): 仕入先・区分・利用者と役割を管理します。

**業務の流れ**

- 社員が品目を探し、購入を依頼します(数量・単価・金額)。
- 上長が決裁します。差し戻すこともあります。
- 購買担当が、決裁済みの依頼をまとめて発注し、発注書を出します。
- 仕入先から納品されたら、検品して入荷を記録します。数が合わないこともあります。
- 入荷の分だけ、在庫が増えます。
- 毎晩在庫を集計し、発注点を割った商品を購買担当に通知します。

**欲しい機能**

- 品目の検索と、詳細の表示と更新(在庫数・単価・区分)
- 購入依頼の入力(明細ごとの数量・単価・金額、合計、依頼番号)と、依頼の一覧(状態で絞る)
- 決裁と差し戻し(スマホでも)と、その通知(画面のお知らせと、メールの代わりのファイル出力)
- 発注(依頼をまとめる)と、発注書の Excel。弊社の発注書のテンプレートに書き込む形にしてください。テンプレートは総務が作り直すことがあるので、差し替えられるようにしてください。
- 入荷の登録(スマホ)と、在庫の一覧
- 夜間の処理(在庫の集計と、発注点を割ったアイテムの通知)
- 仕入先の価格表(CSV)の取り込み。仕入先のシステムが、社内のファイルサーバーの共有フォルダに置きます。置かれたら、人の手を介さずに取り込んでほしいです。いずれサーバーをクラウドに移しても、同じように受け取りたいです。
- 会計に渡す発注データ(CSV)の書き出し
- 月次の購買の集計(部署ごと・区分ごと)を、同じくテンプレートの Excel で
- 区分のコード(品目の区分・単位・依頼の状態)と、役割ごとの画面と操作の権限

**データの量**: 品目は約 3,000、仕入先は約 30 社です。購入依頼は月に約 600 件で、明細は 1 件あたり平均 3 行です。依頼は 5 年分を残したいです。価格表の CSV は、1 社で数百〜数千行です。

**守ってほしいこと**

- 金額と数量は右にそろえ、番号は左にそろえてください。
- 画面の操作が重く感じないようにしてください。前のシステムは、画面を開くたびに待たされました。
- テンプレートのロゴ・枠・プルダウン・計算式は、崩さずにそのまま残してください。
- DB のすべてのテーブルと列に、日本語の論理名のコメントを付けてください。
- テーブル定義書を Excel で納めてください。テーブルには弊社のテーブル番号(例 T001)を付けてください。
- スマホでは、決裁と入荷の 2 つが使えれば足ります。
- 外部のメールサービスやクラウドの認証は使わないでください。秘密の情報も入れないでください。
- 成果物の承認は、弊社の総務部が行います。
