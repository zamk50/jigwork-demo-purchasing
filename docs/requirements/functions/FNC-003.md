## FNC-003 役割に応じたメニューを出す

### 目的と利用者

すべての利用者が、ログインの後に自分の役割で使える業務の入口を一覧で見る。役割に許していない業務は、画面にも API にも出さない。

### 業務ルール

- FR-014 1 人の利用者は、役割を 1 つ以上持つ。
- FR-014-AC-01 前提: 社員と上長の役割を持つ利用者を登録した。操作: その利用者でログインする。結果: ログインでき、ログイン中の利用者を返す API が 2 つの役割を返す。
- FR-023 役割を 1 つも持たない利用者は、ログインできない。エラーの文は FR-002 と同じである。
- FR-023-AC-01 前提: 役割を 1 つも持たない利用者を登録した。操作: 正しい社員番号とパスワードでログインする。結果: ログインできず、FR-002-AC-01 と同じエラーの文が出る。
- FR-015 メニューは、利用者の持つ役割ごとの項目を合わせて出す。
- FR-015-AC-01 前提: 社員の役割だけを持つ利用者でログインした。操作: メニューの画面を開く。結果: 項目表の社員の行の 3 項目だけが出る。
- FR-015-AC-02 前提: 社員と上長の役割を持つ利用者でログインした。操作: メニューの画面を開く。結果: 項目表の社員と上長の行の 4 項目が出る。
- FR-016 役割と項目の対応は、次の項目表のとおりである。

  | 役割 | 項目 |
  |---|---|
  | 社員 | 品目の検索・購入依頼の入力・自分の依頼の一覧 |
  | 上長 | 決裁待ちの一覧(自部署) |
  | 購買担当 | 発注・入荷の登録・在庫の一覧・品目の管理・月次の集計・会計への書き出し |
  | 管理者 | 仕入先の管理・区分の管理・利用者と役割の管理 |

  お知らせ(決裁の通知)と発注書の項目は、それぞれの機能の Issue で項目表に足す。

- FR-017 メニューの項目は、役割の順(社員・上長・購買担当・管理者)に、役割ごとにまとめて並べる。
- FR-017-AC-01 前提: 社員と上長の役割を持つ利用者でログインした。操作: メニューの画面を開く。結果: 社員の 3 項目が先に、上長の 1 項目が後に並ぶ。
- FR-018 メニューを返す API は、ログイン中の利用者の役割に対応する項目だけを返す。
- FR-018-AC-01 前提: 社員の役割だけを持つ利用者でログインした。操作: メニューを返す API を呼ぶ。結果: 社員の行の項目だけが返り、ほかの役割の項目は返らない。
- FR-019 先の画面がまだない項目は、「準備中」と添えて出し、選べないようにする。
- FR-019-AC-01 前提: 先の画面がない項目がある。操作: メニューの画面でその項目を押そうとする。結果: 画面は移らず、項目に「準備中」が出ている。

### 例外と境界

- 項目表の項目は、役割の行どうしで重ならない。項目を足すときも、1 つの項目は 1 つの役割の行にだけ置く。

### 扱うデータ

- 利用者
- 役割
- メニュー
