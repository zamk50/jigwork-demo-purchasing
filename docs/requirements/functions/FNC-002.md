## FNC-002 ログアウトする

### 目的と利用者

ログイン中の利用者が、使い終えたときにログアウトする。共用の端末や置き忘れたスマホから、他の人に使われないようにする。

### 業務ルール

- FR-012 ログイン中の利用者は、メニューの画面からログアウトできる。
- FR-012-AC-01 前提: ログイン中。操作: メニューの画面でログアウトする。結果: ログイン画面に移る。
- FR-013 ログアウトしたとき、サーバーの側でそのログインの状態を無効にする。
- FR-013-AC-01 前提: ログアウトした。操作: メニューの画面を開く。結果: ログイン画面に移る。
- FR-013-AC-02 前提: ログアウトした。操作: ログアウトの前と同じ状態でメニューを返す API を呼ぶ。結果: 401 が返る。

### 例外と境界

- ログインの状態が既に切れているときにログアウトしても、エラーにせずログイン画面に移る。
- ログアウトで無効にするのは、その操作をしたブラウザのログインの状態だけである。

### 扱うデータ

- 利用者
